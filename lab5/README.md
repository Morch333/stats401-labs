# Lab 5 — Interactive Network Visualization

This page uses the supplied 50-station, 50-route urban transit dataset. Both
views load the same station and route CSV files with D3.

The force-directed view maps district to node color, daily passengers to node
area, station type to shape, route type to link color, and travel time to link
width. Stations can be dragged, and hovering highlights immediate neighbors.

The matrix groups stations by district. A filled cell marks a direct route,
cell color shows route type, and opacity shows travel time.
