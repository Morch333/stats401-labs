01 / DATASET

What is in this collection?

Each row represents one distinct Open Library catalog record returned by the query subject:science. The dataset includes its Open Library ID, title, author(s), first publication year, edition count, primary language, number of represented languages, and full-text status.

Method: REST API using Python requests and pandas. The script follows the documented page/limit pagination pattern, waits 1.1 seconds between calls, retries temporary failures, and checks IDs for uniqueness before saving the CSV.
