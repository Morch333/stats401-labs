Web Data Acquisition with Python

For this lab, I collected science-related book records from Open Library and displayed them in a sortable table.

About the dataset

The dataset contains 1,000 Open Library records returned by the search subject:science. Each row includes a book ID, title, author, first publication year, edition count, language information, and whether full text is available.

I used Python with requests and pandas to get the data from the Open Library Search API. The script requested 100 records at a time until it reached 1,000, waited briefly between requests, and saved the result as a CSV file.
