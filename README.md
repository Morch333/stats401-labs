# stats401-labs

STATS 401 lab website. Lab 1 demonstrates D3 data loading, binding, and an SVG
bar chart. Lab 2 presents a four-dimensional city visualization using scales,
axes, legends, and tooltips. Lab 3 acquires 1,000 science-book records from the
Open Library Search API with Python and displays them in a sortable table.

Published site: https://morch333.github.io/stats401-labs/
