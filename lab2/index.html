DESIGN JUSTIFICATION

Why these visual channels?

This visualization uses a faceted lollipop design instead of a conventional scatterplot. Population, a ratio variable, is mapped to horizontal length and position on a shared zero-based scale, making city populations easy to compare accurately. Temperature, an interval variable, is mapped to a continuous cool-to-warm color scale, which emphasizes relative thermal differences without implying separate categories. Development level is ordinal, so increasing marker sizes represent the ordered progression from Low to Medium to High. Region is nominal and therefore controls the four labeled panels rather than using an ordered channel. City names appear beside every mark, while tooltips provide all exact values. The design should help viewers compare population within and across regions, locate warmer or cooler cities, and notice whether highly developed cities tend to be larger. Repeating the same scale in each panel keeps comparisons consistent while avoiding the visual crowding of a four-encoding scatterplot.
